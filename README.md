# Portfólio de Jorge

Site estático, responsivo e sem dependências. Abra `index.html` no navegador ou publique a pasta inteira em qualquer serviço de hospedagem estática.

## Antes de publicar

Em `index.html`, substitua:

- `seuemail@exemplo.com` pelo seu e-mail profissional;
- os links `#` de LinkedIn, Instagram e Behance;
- os três cases de demonstração pelos seus projetos reais quando estiverem prontos.

## GitHub Pages

1. Crie um repositório chamado `portfolio` no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/(root)`.
4. O GitHub exibirá a URL pública em poucos minutos.
